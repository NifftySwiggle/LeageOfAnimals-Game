# 🦅 League of Animals (LOA)

[![Play Live](https://img.shields.io/badge/Play%20Live-GitHub%20Pages-00f0ff?style=for-the-badge&logo=github)](https://nifftyswiggle.github.io/LOA/)
[![Tech Stack](https://img.shields.io/badge/Engine-Three.js%20%7C%20WebGL-ff0055?style=for-the-badge)](https://threejs.org/)
[![Audio](https://img.shields.io/badge/Audio-Web%20Audio%20Synth-ffe600?style=for-the-badge)]()

**League of Animals (LOA)** is an action-packed 3D open-world superhero game running entirely in the browser. Swing between towering skyscrapers, ignite supersonic repulsor thrusters, hijack and drive street vehicles, thwart syndicate incursions, and hunt down hidden Golden Bighorn artifacts across a sprawling Metropolis.

---

## 🎮 Playable Heroes

### 🐏 Spider-Ram
*The Agile Web-Slinging Infiltrator*
- **🕸️ Dynamic Web Swinging**: Sling physics-driven web lines from skyscrapers to build momentum and catapult through the skyline.
- **🤸 Parkour Somervault & Rolls**: Perform mid-air double jump flips and rapid ground tuck-and-roll evasion dashes.
- **🧗 Wall Cling & Crawl**: Scale vertical skyscraper facades with gravity-defying adhesion.
- **🎯 Web Stun Blaster**: Fire projectile web blasts to immobilize incoming enemies from afar.
- **💥 3-Hit Combo Strike**: Fluid melee martial arts combo finishing with a signature horn charge.

### 🛡️ Iron-Ram
*The Heavy Armored Tactical Heavyweight*
- **🚀 Omnidirectional Jet Flight**: Ignite dual repulsor jet thrusters to hover, ascend, and glide freely through 3D space.
- **⚡ Supersonic Booster**: Boost through city canyons at breakneck velocity.
- **💥 Plasma Repulsor Cannon**: Fire explosive plasma bolts with area-of-effect blast damage.
- **🌟 Chest Arc Uni-Beam**: Channel reactor energy into a sustained, devastating energy beam.
- **🌋 Kinetic Ground Pound**: Slam down from high altitude to release a destructive radial shockwave.

## 🌆 Metropolis Open World & Features

- **Sprawling Procedural City**: Towering skyscrapers, glass skybridges, neon billboards, and rooftop helipads.
- **🚗 Drivable Traffic & Vehicles**: Approach any civilian vehicle on the streets and press `[F]` to hop in, cruise the boulevards, or drift around city blocks.
- **🚨 Syndicate Threat Portals**: Track down active crime syndicate hotspots across the city districts, eliminate hostile waves, and liberate Metropolis.
- **🛰️ In-Game Tactical Satellite GPS (Hold `[M]`)**: Pull up real-time live satellite radar tracking hero GPS coordinates, altitude, skyscraper footprints, and active threat hotspots.
- **💎 15 Golden Bighorn Artifacts**: Hunt down hidden collectible trophies scattered across tricky rooftops, hidden skybridge underpasses, and high-altitude spires across 4 difficulty tiers.
- **🏆 18 Unlockable Trophies & Achievements**: Earn badges for swinging feats, high-speed flight, vehicle hijacks, combat streaks, and secret discoveries.
- **🎥 Multi-Perspective Camera**: Switch between 3rd-Person Cinematic, 1st-Person (FPS), and Dynamic Action angles at any time.
- **☀️ Dynamic Time of Day & Weather**: Experience daytime sunlight, golden hour sunsets, neon-lit nightscapes, and atmospheric rain particles.
- **🔊 Synthesized Dynamic Sound Engine**: Fully procedural Web Audio synthesizer powering web swooshes, jet hums, combat impacts, engine revs, and ambient synth music.

## 🕹️ Default Controls

| Action | Keyboard / Mouse |
| :--- | :--- |
| **Move** | `W`, `A`, `S`, `D` |
| **Look / Aim** | `Mouse` |
| **Melee Attack / Fire** | `Left Click` (Mouse 0) |
| **Web Swing / Jet Flight** | `Hold Right Click` (Mouse 2) |
| **Jump / Double Jump Flip** | `Spacebar` |
| **Tuck & Roll Dash** | `Left Shift` |
| **Web Stun Shooter** | `E` |
| **Wall Climb & Cling** | `Q` |
| **Drive / Hijack Vehicle** | `F` |
| **Toggle Camera (1st / 3rd)** | `V` |
| **Hold Tactical GPS Map** | `Hold M` |
| **Pause Menu & Settings** | `ESC` |

> *All hotkeys and mouse bindings can be remapped directly in the in-game Controls menu with automatic persistence.*

## ⚡ Technology

- **Renderer**: Three.js & WebGL with custom GLSL shaders (bloom, atmosphere, particle emitters).
- **Physics**: Custom 3D collision detection, pendulum web-swinging math, projectile ballistics, and vehicle suspension physics.
- **Audio**: Web Audio API Procedural Synthesizer.
- **Storage**: LocalStorage for keybindings, sound preferences, achievements, and collectible tracking.
- **Zero Dependencies**: 100% client-side web application — runs instantly on any modern browser.
