# 🦅 League of Animals (LOA)

An epic 3D open-world superhero action game built with Three.js and WebGL. Play as **Spider-Ram** or **Iron-Ram** with web swinging, supersonic repulsor flight, plasma cannons, drivable vehicles, incursion portal missions, and hidden Golden Bighorn collectibles across a sprawling voxel Metropolis.

---

## 🎮 Features
- **Two Playable Heroes**:
  - **Spider-Ram**: Web-slinging, parkour somersault tuck rolls, web stun blaster, wall climbing, 3-hit combo strikes.
  - **Iron-Ram**: Omnidirectional jet flight & hover, supersonic booster, plasma repulsor cannon, chest Arc Uni-Beam, kinetic ground pound shockwave.
- **Dynamic Metropolis**: Sprawling procedural city with skyscrapers, skybridges, animated traffic cars with real-time driving & hijacking physics, destructible physics props.
- **In-Game Tactical Map**: Press & Hold `[M]` for real-time satellite GPS tracking with altitude coordinates & threat indicators.
- **Customizable Controls**: Full keybinding and mouse remapping system with automatic persistence.
- **Achievements & Collectibles**: 18 unlockable achievements across tiered difficulty ranks + 15 hidden Golden Bighorn Artifacts.
- **Synthesized Dynamic Audio**: Web swooshes, repulsor jet hums, combat impacts, engine roars, and ambient atmospheric audio.

---

## 🚀 Quick Start Locally

Since this is a client-side WebGL application with ES modules, run any local HTTP server:

```bash
# Using npx serve
npx serve .

# Or using Python
python -m http.server 8000
```

Open `http://localhost:3000` (or `http://localhost:8000`) in any modern desktop browser with WebGL enabled.
